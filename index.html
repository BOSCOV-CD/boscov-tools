How to run

Two minutes, no installation.

  1. Download the tool you want above.
  2. Right-click the file → Run with PowerShell (or run powershell -ExecutionPolicy Bypass -File "BOSCOV Boost.ps1").
  3. Approve the UAC prompt — the script backs everything up first, then applies the tweaks.
  4. Changed your mind? Revert anytime: powershell -File "BOSCOV Boost.ps1" -Revert
